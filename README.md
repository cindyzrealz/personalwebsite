# Personal Website

Built with static HTML, CSS, and vanilla JavaScript. Deployed on Vercel/Netlify.

## Structure

- `/` — Homepage (hub)
- `/intro1.html` — Intro sequence, step 1 (tone-setting)
- `/intro2.html` — Intro sequence, step 2 (navigation reveal)
- `/writing/` — Writing directory with category filters
- `/writing/game-theory.html` — Individual piece template
- `/carving/` — Stone carving and seal carving portfolio with lightbox
- `/projects/videogame1.html` — Video game intro screen
- `/projects/videogame2.html` — Video game script showcase
- `/about/` — About page (content TBD)

## Design References

- ribo.zone — typography, spacing, navigation structure
- omori-game.com/en/whitespace — atmosphere, animation choreography
